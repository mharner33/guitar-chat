# Reading the Fretboard

The guitar fretboard looks like a grid of hundreds of positions, but it is built from a handful of rules. Learn how strings are numbered, what each fret adds, and how a few interval shapes repeat, and you can find any note or chord tone without memorising the whole neck.

Everything below assumes standard tuning and the same conventions this corpus uses everywhere: strings are numbered from the highest-pitched string, and tab is written from the lowest string to the highest.

## String numbering and open strings

| String | Open note | Pitch |
|---|---|---|
| 6 | E | E2 (lowest, thickest) |
| 5 | A | A2 |
| 4 | D | D3 |
| 3 | G | G3 |
| 2 | B | B3 |
| 1 | E | E4 (highest, thinnest) |

String 1 is the high E and string 6 is the low E. They have the same letter name, two octaves apart. Tab such as the open C major chord, `x-3-2-0-1-0`, lists the strings in order 6, 5, 4, 3, 2, 1, so the first character is the low E string and `x` means that string is not played.

Reading the open strings from low to high gives E A D G B E. Each neighbouring pair is a perfect fourth apart (5 semitones), except G to B, which is a major third (4 semitones). That single exception explains almost every "except on the B string" rule guitarists learn.

## One fret is one semitone

Each fret raises the pitch by one semitone. Twelve frets make an octave, so the 12th fret plays the same note as the open string, one octave higher. The fret pattern then repeats: fret 13 matches fret 1, fret 15 matches fret 3, and so on.

Between natural notes there are two semitones except in two places: B to C and E to F are only one semitone apart. So on string 6, open E is followed directly by F at fret 1, then F# at fret 2, G at fret 3, and so on up to E again at fret 12.

## Octave shapes

The same note appears in several places, and the octave shapes connect them. An octave is 12 semitones.

- Root on string 6: the octave is on string 4, two frets higher.
- Root on string 5: the octave is on string 3, two frets higher.
- Root on string 4: the octave is on string 2, three frets higher (crossing the G–B gap adds a fret).
- Root on string 3: the octave is on string 1, three frets higher.
- Strings 6 and 1 at the same fret are two octaves apart.

For example, G at string 6 fret 3 has its octave at string 4 fret 5. C at string 5 fret 3 has its octave at string 3 fret 5 and again at string 1 fret 8.

## Finding a root on strings 6 and 5

Most movable chords and scale shapes take their root from string 6 or string 5, so these two strings are the first to learn.

| Note | String 6 fret | String 5 fret |
|---|---|---|
| A | 5 | 0 or 12 |
| B | 7 | 2 |
| C | 8 | 3 |
| D | 10 | 5 |
| E | 0 or 12 | 7 |
| F | 1 | 8 |
| G | 3 | 10 |

A useful link between the two columns: any note on string 6 is also found on string 5 five frets lower. A on string 6 fret 5 equals open A on string 5, and C on string 6 fret 8 equals C on string 5 fret 3. Sharps and flats sit one fret either side, so F# is string 6 fret 2 and Bb is string 5 fret 1.

## Intervals as shapes

Because the strings are tuned regularly, each interval has a fixed shape that you can slide anywhere. Measuring from a root to a note on the next higher string:

- **Major third (4 semitones):** one string up, one fret back. From C at string 5 fret 3, the major third E is at string 4 fret 2.
- **Minor third (3 semitones):** one string up, two frets back. From A at string 6 fret 5, the minor third C is at string 5 fret 3.
- **Perfect fourth (5 semitones):** one string up, same fret. From A at string 6 fret 5, D is at string 5 fret 5.
- **Perfect fifth (7 semitones):** one string up, two frets higher. From G at string 6 fret 3, D is at string 5 fret 5.
- **Octave (12 semitones):** two strings up, two frets higher — three frets higher when the jump crosses the G–B pair (from string 4 or 3).

## The G–B exception

Every shape above assumes a fourth between neighbouring strings. Between string 3 (G) and string 2 (B) the gap is a major third, one semitone smaller, so any shape that crosses that pair moves one fret higher to compensate.

- Major third across G–B: one string up, same fret. Open G and open B are already a major third apart.
- Minor third across G–B: one string up, one fret back.
- Perfect fourth across G–B: one string up, one fret higher.
- Perfect fifth across G–B: one string up, three frets higher.
- Octave across G–B (from string 4 or 3): two strings up, three frets higher. From D at string 4 fret 0, the octave D is at string 2 fret 3.

Once you see that the B string is "one fret out of line", chord and scale shapes that look irregular start to make sense: they are the same intervals, adjusted for the tuning.
