# Minor Third

The **minor third** (m3) spans **3 semitones** (1 whole + 1 half step). Measured up from C it is **C–Eb**.

It is an imperfect consonance. Inverting it within the octave gives the [Major Sixth](/intervals/major-sixth.md).
