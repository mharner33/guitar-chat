# Minor Second

The **minor second** (m2) spans **1 semitone** (one half step). Measured up from C it is **C–Db**.

It is a dissonance. Inverting it within the octave gives the [Major Seventh](/intervals/major-seventh.md).

*Also called:* half step, semitone.
