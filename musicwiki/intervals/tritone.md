# Tritone

The **tritone** (TT) spans **6 semitones** (3 whole steps). Measured up from C it is **C–F#**.

It is a dissonance (the tritone). Inverting it within the octave gives the [Tritone](/intervals/tritone.md).

*Also called:* augmented fourth, diminished fifth.
