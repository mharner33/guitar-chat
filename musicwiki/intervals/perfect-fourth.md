# Perfect Fourth

The **perfect fourth** (P4) spans **5 semitones** (2 whole + 1 half step). Measured up from C it is **C–F**.

It is a perfect consonance (though treated as a dissonance in some counterpoint). Inverting it within the octave gives the [Perfect Fifth](/intervals/perfect-fifth.md).
